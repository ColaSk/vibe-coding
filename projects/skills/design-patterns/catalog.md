# 模式目录

按变化点查。每条只保留：变化点、稳定点、最小形态。

## 对象与函数

| 变化点 | 模式 | 稳定点 | 最小形态 |
| --- | --- | --- | --- |
| 算法或策略可替换 | Strategy | 调用流程 | 一个接口，多个实现，调用方持有接口 |
| 一系列步骤固定，某几步不同 | Template Method | 步骤顺序 | 骨架方法 + 少数可覆盖步骤 |
| 创建过程复杂，产品类型会变 | Factory / Builder | 使用方 | 创建函数或建造者；使用方不 new 具体类 |
| 要在不改原对象的前提下加行为 | Decorator | 原接口 | 同一接口的包装，只加一层职责 |
| 外部系统接口不匹配 | Adapter | 本系统接口 | 一个转换层，外面的类型不外泄 |
| 子系统调用步骤多且易变 | Facade | 对外一个入口 | 一个门面，里面的类型保持私有 |
| 一对多通知，观察者集合会变 | Observer | 发布者职责 | 订阅接口；不要用全局事件总线代替依赖 |
| 对象内部状态决定行为，状态会迁移 | State | 上下文的对外行为 | 状态对象 + 显式迁移 |
| 树形结构，部分与整体要同样操作 | Composite | 调用方的操作 | 同一接口的叶与容器 |
| 需要撤销、排队或记录操作 | Command | 调用方与执行方 | 命令对象，携带执行所需参数 |
| 遍历方式与集合存储分离 | Iterator | 集合实现 | 迭代器；语言已有的优先用语言的 |
| 多个同事对象不能互相引用 | Mediator | 同事的职责 | 一个协调者；同事只跟协调者说话 |
| 共享不可变实例以省成本 | Flyweight | 外部状态在调用方 | 不可变共享核 + 外部状态参数 |
| 延迟或控制访问 | Proxy | 真实对象接口 | 同接口代理，负责缓存、权限或远程 |

单例不在表内。需要唯一实例时，在组合根创建一次并传下去。

## 模块与架构

| 变化点 | 模式 | 稳定点 | 最小形态 |
| --- | --- | --- | --- |
| 领域规则不能跟着入口或存储变 | 分层 / 六边形 | 领域接口 | 入口与存储是适配器，依赖指向领域 |
| 一条业务能力要能单独改、单独部署 | 按能力切模块 | 模块对外契约 | 一个能力一个模块，禁止跨模块摸内部 |
| 读模型和写模型复杂度不同 | CQRS | 写侧不变量 | 分开读模型和写模型；事件溯源另说，不默认上 |
| 请求处理步骤会增删 | 管道 / 中间件 | 管道入口与上下文 | 有序步骤，每步只看上下文 |
| 失败后要重试、缓冲、削峰 | 队列 + 消费者 | 生产者的请求路径 | 生产者只入队；消费者幂等 |
| 多来源变更要通知多个下游 | 发布订阅 | 发布者不知道订阅者 | 事件表达已发生的事实，不表达命令 |
| 外部依赖不稳定 | 防腐层 | 本领域模型 | 边界上翻译，领域内不用外部类型 |
| 同一端口多种适配器 | 端口与适配器 | 端口 | 应用定义端口，基础设施实现 |
| 长流程跨多步且会失败 | 流程 / Saga | 每步的本地事务 | 显式步骤与补偿，不藏在回调里 |
| 配置决定组装哪些实现 | 组合根 | 业务代码无全局查找 | 启动时组装，运行时只使用注入的依赖 |

## 界面与交互

| 变化点 | 模式 | 稳定点 | 最小形态 |
| --- | --- | --- | --- |
| 同一数据多种展示，展示会变 | 视图与状态分离 | 状态更新路径 | 状态在一处，视图只渲染 |
| 页面由可替换区块组成 | 组合组件 | 页面骨架 | 容器决定布局，区块通过 props 或插槽进入 |
| 列表项的结构相同、内容不同 | 列表项组件 | 列表容器 | 一项一个组件，容器只负责收集 |
| 操作分步且可返回 | 向导 / 步骤状态 | 每步的校验 | 一步一个组件，步骤索引在父级 |
| 局部反馈不打断当前任务 | 就地状态 | 页面其他部分 | 加载、空、错误贴着触发它的区块 |
| 一个入口触发一组相关动作 | 命令式动作条 | 动作的可用性规则 | 动作列表由状态派生，不散落在按钮里 |
| 控件外观要换、交互语义不变 | 无头交互 + 皮肤 | 键盘与状态语义 | 状态与按键在一处，样式在外层 |
| 服务端数据与屏幕不同步 | 查询与变更分开 | 屏幕渲染 | 查询缓存和变更分开；变更成功后再更新那一块 |
| 多个控件编辑同一草稿 | 受控草稿 | 提交载荷 | 一个草稿对象，控件只读写字段 |
| 频繁出现的空、错、权限不足 | 状态视图 | 正常内容组件 | 三种状态是正常内容旁的固定出口 |
